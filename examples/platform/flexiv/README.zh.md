# flexiv 平台示例

[English](README.en.md)

每个项目链接都指向含源码和 xmake.lua 的目录。横线表示该语言尚无此类示例。

安装对应平台和语言后，在项目目录执行 xmake build 生成 Wasm，再执行 xmake test -j1 运行注册的测试。
