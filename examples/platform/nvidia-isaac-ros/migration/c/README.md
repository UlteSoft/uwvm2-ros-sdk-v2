# nvidia-isaac-ros · C resource migration

The offline build embeds the pinned ROS 2 IMU definition. To build with NVIDIA's tensor definition, set `WROS_ROS_PACKAGE_ROOT` to the local `isaac_ros_tensor_list_interfaces` package. Xmake defaults to the 5.0.0 lock. For 5.1.0, configure the project with `xmake f -c -y -a wasm32 --isaac_ros_release=5.1`, then build and test. The selected lock verifies both `Tensor.msg` and `package.xml` before embedding the resource. [Build and test](../../../../../document/en/platform-migration-examples.md).

The Wasm test checks the embedded resource in guest memory. DDS exchange, `rosidl::Buffer` CUDA transport and TensorRT or Triton execution require their own runtime tests. [Isaac ROS 5.0.0 sources](https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_common/tree/7bec6ae5dbb2faa11617f40226e8932a4a94e6e4), [Isaac ROS 5.1.0 sources](https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_common/tree/57a6485a1322e38791b1cb21c20a9e897fbc50a5), [Isaac ROS 5.1 documentation](https://nvidia-isaac-ros.github.io/v/release-5.1/repositories_and_packages/isaac_ros_dnn_inference/index.html).
