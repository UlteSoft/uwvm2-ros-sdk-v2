# 平台接口

安装时用下列平台 ID 和语言选择接口。每个平台提供 C、C++98 至 C++26、WAT、Rust、AssemblyScript、JavaScript 和 TypeScript 的 Xmake 工程。
每页给出读取字段、输入编码和固定版本的上游文件。各厂商示例在 guest 内存中读取离线数据。

单个平台的开发流程和完整上游验收要求见[平台验收](../document/zh/platform-qualification.md)。

- 通用场景 ABI。[generic](generic/README.zh.md)
- Go 提供 25 种 ABB ROS 1 消息、22 对服务请求和响应以及 Header 的类型和双向编解码器。[ABB](abb/README.zh.md)
- Go 支持 43 种 Unitree ROS 2 消息类型，Go2 与 HG LowState 有双端序编解码器。[unitree](unitree/README.zh.md)
- C、C++ 和 Rust 可编解码 25 种 ABB ROS 1 消息、22 对服务请求与响应，以及公共的 Header。 [abb](abb/README.zh.md)
