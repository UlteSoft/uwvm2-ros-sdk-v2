# Language coverage by legacy selection

The v1 catalog at `466ec1647ae8577bc2c16bd4f8df8162636817f4` has 29 selection IDs, including a C interoperability bridge. Source locations below refer to the archived v2 baseline `476799fc80b1ebeea82721a82d658dee75fce9a6` unless marked v1. Results describe the new SDK and do not imply full release qualification. [Frozen qualification evidence](qualification.md)

Candidate `947c3067` includes the pinned Node executable.

## Source evidence for additional languages

After removing the interoperability bridge and counting both Go toolchains once, the 29 legacy selections represent 26 high-level languages plus WAT. Four further candidates for the goal of more than 30 distinct languages come from the 300-package cohort. Common Lisp implements ROS message conversion methods in `cl_transforms_stamped`. The Ada sample declares a generated ROS time binding. VRPN includes a Tcl application script and a host-side Perl RPC generator. SDK compiler, guest-library and platform qualification are pending for all four. [Pinned sources, roles and digests](../../src/qualification/corpus/additional-language-inputs.json)
