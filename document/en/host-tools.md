# Official host tools

The selected SDK supplies `bin/xmake` and `bin/uwvm2-ros`. Both `plan` and `install` resolve the releases for the running Python process's ELF ABI. If a release is missing, both report the tool and host. An installation verifies the published bytes, places each tool under the selected prefix and records its origin in `share/host-tools/origins.json`.

On x86-64 the installer downloads the Xmake 3.0.5 ELF published by xmake-io. On i686, AArch64, ARM soft-float and ARM hard-float the provider uses Debian's pinned Xmake packages. Its `bin/xmake` launcher locates the packaged ELF and resources relative to the selection. Unmodified upstream binaries come from their publishers. The SDK cache keys downloaded assets by their published SHA-256. [Official Xmake release](https://github.com/xmake-io/xmake/releases/tag/v3.0.5) · [Debian package lock](../../src/host-tools/xmake/debian-packages.json)

The VM release lock names the upstream commit and records each available host under `tools.uwvm2-ros.hosts`. For a single-member USTAR `.tar.xz` asset, the entry contains the exact GitHub release `tag`, asset filename `asset`, `format` set to `tar.xz`, `member` set to `uwvm2-ros`, the archive's `compressed_bytes` and `compressed_sha256`, and the ELF's `bytes` and `sha256`. A raw `elf` uses the ELF length and digest directly. Installation checks both layers and the executable's Linux ABI, including the ARM float calling convention. The lock pins all five Linux host binaries from the [VM prerelease](https://github.com/UlteSoft/uwvm2-ros/releases/tag/wros-vm-6de97ade53a7). [Host release lock](../../src/host-tools/releases.json) · [VM source pin](../../src/host-tools/uwvm2-ros/UPSTREAM.json)

The separate `rebuild` action builds Xmake from its pinned upstream release source, fetches the pinned VM commit and tree, then builds the interpreter and LLVM AOT engine. A native rebuild requires a compatible LLVM 23 C++26 toolchain, LLD, Python, CMake, Ninja, GNU Make, Perl and the Linux development files for that VM revision. Allow space under the prefix for the LLVM and runtime build trees. [VM project](https://github.com/UlteSoft/uwvm2-ros)
