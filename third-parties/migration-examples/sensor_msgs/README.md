# ROS 2 sensor_msgs resource fixture

This subset contains the unmodified manifest, IMU message and Apache 2.0 license from [ROS 2 common_interfaces at a941f14](https://github.com/ros2/common_interfaces/tree/a941f14bb318d8d904505ed935ccbb97f24a70a4/sensor_msgs). The SDK uses the original bytes as an offline example for exact package URI lookup. Building or installing the entire upstream sensor_msgs package requires its other sources.
