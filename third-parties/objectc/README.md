# Objective-C runtime sources

The SDK builds a guest-side static runtime from the included official GNUstep libobjc2 2.3 source release at commit `e877e782fb965c4e870d2ecf6aff58dddc6290ae` and Tessil robin-map 1.4.0. The SDK verifies both archive digests before extraction. Their MIT licenses accompany the source. CMake dependency downloads are disabled. [GNUstep libobjc2](https://github.com/gnustep/libobjc2/releases/tag/v2.3) · [Tessil robin-map](https://github.com/Tessil/robin-map/tree/v1.4.0)

`libobjc2-wasm.patch` contains the single-thread Wasm port. It uses guest allocation for internal pages, excludes executable block trampolines and the Objective-C exception personality, and avoids implicit host logging and environment-based profiling. Object construction checks allocation sizes and propagates allocation failure as nil. The two Clang patches select the GNUstep 2.0 ABI on Wasm and emit a typed zero result for messages to a nil receiver. The public SDK headers and both compiler source patches are installed with the Objective-C language package.
