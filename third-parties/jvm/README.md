The Java sources and C resource templates in this directory are a Wasm-specific derivative of TeaVM 0.13.1 at commit `b3a245b7d9034ff35cdfab2def057a3d4f256efb`, distributed under the accompanying Apache-2.0 license. `UPSTREAM.json` identifies each modified upstream file. The resources replace process-local pointer compression, configure the synchronous launcher, and route guest allocations through the nonmoving Wasm collector. `teavm-wros.patch` records the source changes. The host compiler bundle has independent per-language manifests, and its Maven URLs and licenses are recorded in the SDK1 JVM provenance collection.

`teavm-java-shifts.patch` applies to the pinned upstream C expression generator. It preserves Java's shift-distance masking and two's-complement left shifts when Clang compiles the generated C to Wasm.
