# SDK sysroot qualification cases

[简体中文](README.zh.md)

The suite records the source SHA-256, the SDK case kind and the related upstream paths for each local case. The upstream programs have their own entries and results. [Case manifest and upstream revisions](../cases.json)

* `search_lsearch_full_width.c` ports the ten initial keys, successful and unsuccessful lookups, duplicate insertion and final append from libc-test at `18e28496adee3d84fefdda6efcb9c5b8996a2398`. Each key occupies a full 80-byte record, including the empty string. The port fills the destination with nonzero bytes and checks the entire record after each append. It uses a comparator with the signature expected by `lfind` and `lsearch`. It runs in the sixteen sysroot profiles. [Upstream test](../upstream/libc-test/src/functional/search_lsearch.c) · [License](../upstream/libc-test/COPYRIGHT)
* `sem_getvalue_unnamed.c` is an SDK companion to the Open POSIX tests in wasi-libc at `2e6fb9d8ee0cdf9e431fbcabe8af3115de000a13`. The original `sem_getvalue` test opens and unlinks a named semaphore. The SDK case initializes a process-private unnamed semaphore with one token. It checks the count before and after consuming the token and again after joining a worker that posts. Each operation must succeed for the case to pass. It runs in the eight threaded profiles. [Upstream sem_getvalue test](../../../compilers/cc/wasi-libc/test/open-posix-test-suite/conformance/interfaces/sem_getvalue/1-1.c) · [Upstream sem_init test](../../../compilers/cc/wasi-libc/test/open-posix-test-suite/conformance/interfaces/sem_init/1-1.c)
* `pthread_rwlock_init_join.c` is an SDK companion to the Open POSIX reader test from the same wasi-libc revision. The original polls a flag shared with a worker thread. The SDK case initializes the attributes and lock, joins the worker that acquired and released the read lock, then checks that the lock admits a writer. It runs in the eight threaded profiles. [Upstream pthread_rwlock_init test](../../../compilers/cc/wasi-libc/test/open-posix-test-suite/conformance/interfaces/pthread_rwlock_init/1-1.c)
