# PHP 8.4.13

[简体中文](README.zh.md)

The PHP release supplies the Zend engine, generated parser, embed and CLI sources, and standard, date, hash, JSON, PCRE and random extensions. The retained WASI code adjusts the Zend allocator for partial page mappings, handles guard-page availability for fibers and removes a parent-process fallback from the entropy provider.

The standalone runtime Wasm, installable language entry point and external guest project still require qualification. [Upstream identity, licenses and changes](upstream.json) · [Original release file digests](upstream.sha256)
